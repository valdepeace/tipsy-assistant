EMPIEZA EN UNOS PASOS

Tu primera charla
empieza aquí.

La guía usa la versión alpha actual. Necesitas Rust, micrófono, altavoces y una clave de proveedor o un servicio local compatible.

Ver configuración avanzada en GitHub ↗
VERSIÓN ACTUAL0.1.0-alpha.1Las opciones pueden cambiar durante la alpha.
01

Prepara el entorno

Instala Rust 1.96.1 o posterior y conecta un micrófono y unos altavoces.

Instalar Rust ↗
02

Descarga el proyecto

Clona el repositorio y entra en la carpeta:

git clone https://github.com/valdepeace/tipsy-assistant.git
cd tipsy-assistant
03

Guarda tu clave

Para OpenRouter, obtén una clave en su web. El comando la guarda en el almacén de credenciales de tu sistema.

cargo run -p tipsy-assistant -- key set openrouter

También puedes configurar un endpoint compatible en el paso siguiente.

04

Arranca y configura

cargo run -p tipsy-assistant

Pulsa F9 para elegir proveedores, modo de escucha y perfil. Pulsa Tab para hablar.

◈

Tu clave no va en la web. Se introduce en tu equipo y se guarda en su almacén seguro. Esta página nunca te pedirá credenciales.
